# 历史数据按日期查询说明

历史数据查询页面已经从“按样本数量查询”改为“按日期范围查询”。

## 查询规则

- 开始日期、结束日期必须同时填写。
- 结束日期不能早于开始日期。
- 单次查询最多 10 个自然日。
- 结束日期当天的数据会被包含在查询结果中。
- 超过 10 天时，前端立即提示；后端也会再次校验并返回错误，避免绕过前端限制。

示例：

- 2026-09-01 ～ 2026-09-10：允许（10 个自然日）
- 2026-09-01 ～ 2026-09-11：拒绝（11 个自然日）

## API

兼容原有的样本数量接口：

`GET /api/io/:name/history?limit=120`

新增日期范围接口：

`GET /api/io/:name/history?start_date=2026-09-01&end_date=2026-09-10`

日期查询最终从 SQLite `data/history.db` 的 `point_history` 表按时间范围读取数据。
